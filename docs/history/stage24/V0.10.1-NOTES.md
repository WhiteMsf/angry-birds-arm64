# v0.10.1 — Box2D 2.1.2 PostSolve API compile fix

v0.10 failed at compile time because the contact probe used:

`b2ContactImpulse::count`

That member belongs to newer Box2D APIs. The pinned 2.1.2-era
`b2ContactImpulse` exposes the impulse arrays, but the number of valid contact
points must be read from:

`contact->GetManifold()->pointCount`

v0.10.1 changes only the diagnostic `PostSolve` telemetry code:

```cpp
const b2Manifold* manifold = contact->GetManifold();
int count = manifold ? manifold->pointCount : 0;
```

and sums `normalImpulses[0..count)`.

The recovered ARMv7 `BeginContact` momentum metric, original Lua frame loop,
Box2D contact listener, Level1 state and gameplay behavior are unchanged.
