# v0.11.1 — Stage 10 C++ string-literal compile fix

v0.11 did not reach runtime. Three diagnostic `printf`/`fprintf` strings were
generated with a literal newline inside the C++ quoted string instead of the
escape sequence `\n`.

Clang therefore reported `missing terminating '"' character` around the Stage
10 initial-state and error-boundary logs.

v0.11.1 changes only those three source literals to use `\n`.

No recovered collision formula, strength/defence mutation, Lua
`blockCollision()` dispatch, Box2D behavior, Level1 state, or semantic
verification changed.
