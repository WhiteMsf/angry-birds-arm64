# v0.15.3.1 — compile-only hotfix

v0.15.3 did not reach runtime.

The new raw-contact diagnostic helper was declared as a `const` member:

```cpp
void dumpContactCandidates(...) const
```

but Box2D 2.1.2 exposes:

```cpp
b2Contact* b2World::GetContactList()
```

as a non-const member function.

Clang therefore rejected the call through the const-qualified
`PhysicsBridge`.

## Fix

Removed only the trailing `const` qualifier from
`dumpContactCandidates()`.

No probe geometry, timing, contact logic, bird state, filters, damage,
scoring, Box2D behavior, or verifier logic changed.
