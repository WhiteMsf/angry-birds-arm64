# v0.18.1 — compile-only hotfix

v0.18 did not reach runtime.

The Stage 17 slingshot probe stored the original Lua bird name in a
`std::string`:

```cpp
std::string slingBirdName;
```

but `PhysicsBridge::find()` is declared as:

```cpp
b2Body* find(const char* name);
```

One call site passed the `std::string` object directly:

```cpp
physics.find(slingBirdName)
```

Clang correctly rejected that conversion.

## Fix

Changed only that call to:

```cpp
physics.find(slingBirdName.c_str())
```

No slingshot timing, input emulation, Lua state, impulse math, Box2D behavior,
collision behavior, or verifier logic changed.
