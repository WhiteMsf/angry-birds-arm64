# v0.18.2 — headless pause-button guard + screen/world cursor separation

v0.18.1 compiled and reached the first real Stage 17 input frame.

The original `updateGame()` failed at stripped bytecode PC 478 with:

```text
attempt to compare number with nil
```

Exact bytecode around that PC is:

```text
471 GETGLOBAL keyPressed
472 GETTABLE  "LBUTTON"
...
475 GETGLOBAL cursor
476 GETTABLE  "x"
477 GETGLOBAL pauseButtonW
478 LT        cursor.x, pauseButtonW
...
480 GETGLOBAL cursor
481 GETTABLE  "y"
482 GETGLOBAL pauseButtonH
483 LT        cursor.y, pauseButtonH
```

`pauseButtonW` and `pauseButtonH` are normally created by the original
`createMenuPages()` path. The headless bootstrap deliberately does not build
those UI/menu objects, so the pause-button guard had nil extents.

There was also a coordinate-space mistake in the Stage 17 harness:
`cursor` is screen/UI space, while `cursorPhysics` and `cursorWorld` are
game/world coordinates. The first probe incorrectly copied the bird's
negative world coordinates into screen-space `cursor`.

## Fix

- supply headless `pauseButtonW = 0`, `pauseButtonH = 0`;
- keep screen-space `cursor` / `oldCursor` at `(100,100)`;
- continue feeding the real bird/pull positions only through
  `cursorPhysics` / `cursorWorld`;
- add a Stage 17 UI-guard telemetry line.

No slingshot formula, bird physics, timing, release logic, or verifier
semantics changed.
