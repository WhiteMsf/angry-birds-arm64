# v0.18.5 — selection-boundary diagnostic

v0.18.4 is the first Stage 17 run that completed the full 180-frame headless
driver without a missing camera/UI dependency. That exposed the real current
boundary:

```text
READY frame=62
AFTER PRESS: dragStarted=true, selectedBird=nil
```

Because `selectedBird` was nil, the original held-drag branch never executed:

```text
rubberBandLength=0
shootMaxLength=nil
applyImpulseCalls=0
```

This version deliberately does **not** guess at the missing input semantic.

## Added diagnostics

- Dumps original `updateGame` Lua 5.1 bytecode PCs 620..780, including
  GETGLOBAL/SETGLOBAL/LOADK constants and RK constants.
- Surfaces constant-table indices for the sling-selection globals:
  `LBUTTON`, `touchcount`, `currentBirdName`, `selectedBird`, `birdReady`,
  cursor variants, drag state, shoot/rubber-band globals, and objects/world.
- Before PRESS logs:
  - birdReady/currentBirdName;
  - touchcount;
  - keyPressed/keyHold;
  - Box2D bird position;
  - Lua object x/y;
  - cursorPhysics/cursorWorld/cursor screen position;
  - shootRange.
- If `selectedBird` remains nil, exits immediately with a compact selection
  diagnostic rather than performing a meaningless drag/release.
- Corrects the AFTER DRAG telemetry label so it reads the actual
  `selectedBird` global instead of printing `currentBirdName`.

No gameplay, physics, sling formula, timing, or input values were changed.
