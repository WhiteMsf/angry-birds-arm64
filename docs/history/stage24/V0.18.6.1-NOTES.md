# v0.18.6.1 — compile-only forward declaration fix

v0.18.6 did not reach runtime.

Clang failed at `stage17_headless_screen_from_physics()` because that helper
was inserted before the existing definition of:

```cpp
static double get_global_number(lua_State* L, const char* name)
```

The source therefore called `get_global_number()` before it had been declared.

## Fix

Added only this forward declaration before the new screen/physics helper:

```cpp
static double get_global_number(lua_State* L, const char* name);
```

No Stage 17 runtime behavior changed.

In particular, this does **not** change:
- PRESS/DRAG/RELEASE timing;
- the v0.18.6 screen→world→physics input mapping;
- pause/camera headless boundaries;
- original Lua selection logic;
- rubber-band math;
- Box2D;
- `applyImpulse`;
- verification criteria.

This patch exists solely to let v0.18.6 compile so its runtime hypothesis can
actually be tested.
