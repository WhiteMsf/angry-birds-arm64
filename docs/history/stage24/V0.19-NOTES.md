## Stage 18 objective

Enable the already recovered ARMv7 **exactly-one-special** collision-damage
branch for the naturally launched `RedBird_4`.

The controlled Stage 15/16 restriction to `WoodBlock2_6` is removed. The
formula itself is unchanged:

```text
collisionForce =
    (birdMass * |birdVelocity| / 10) * damageMultiplier

requestedDamage = collisionForce - defence
newStrength     = oldStrength - requestedDamage

original birdCollision(
    birdName,
    targetName,
    collisionForce,
    floor(actualDamage))
```

If the natural target dies, the previously validated legacy destruction path
is allowed to run (`deadBlocks`, overkill velocity scaling, contact disable,
removeBlocks/removeObject).

a real Level1 object and enters the recovered original bird-damage pipeline.
