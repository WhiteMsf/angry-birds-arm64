# v0.20 — Stage 19: full natural shot lifecycle

Stage 18 / v0.19 passed on its first run:

```text
original input -> sling -> applyImpulse -> ballistic Box2D flight
-> natural RedBird_4/WoodBlock4_1 contact
-> recovered bird damage
-> original birdCollision()
-> deadBlocks
-> removeBlocks()
-> reconstructed removeObject()
```

Stage 19 removes the last damage-isolation boundary and lets one shot finish.

## Changes

### Both recovered damage families are active

```text
enableRecoveredBirdDamage  = true
enableRecoveredBlockDamage = true
```

### Stage 13 ordinary destruction is merged into the combined harness

The old diagnostic stop at the ordinary block-destruction boundary is replaced
with the already-validated Stage 13 path:

```text
newStrength = oldStrength - (collisionMetric - defence)

if newStrength <= 0:
    write newStrength
    actualDamage = oldStrength
    deadBlocks[name] = objects.world[name]

original removeBlocks()
    -> destruction bookkeeping / score / particles
    -> reconstructed removeObject(name)
    -> b2World::DestroyBody
```

### Bird damage is no longer a one-contact probe

Stage 18 intentionally mutated only its first natural bird contact. Stage 19
keeps the same recovered RedBird_4 exactly-one-special formula active for each
natural BeginContact.

### Full post-shot lifecycle observation

The driver can now run for up to 1200 render frames (20 seconds), but exits as
soon as original Lua reaches either:

- a different `currentBirdName` with `birdReady=true`, or
- `levelCompleted=true`.

The harness does not create the next bird and does not force victory.

### Long-run body safety

Since objects can now die naturally, the driver re-resolves the first bird and
pig from the native body map instead of retaining potentially dangling Box2D
pointers after `removeObject()`.
