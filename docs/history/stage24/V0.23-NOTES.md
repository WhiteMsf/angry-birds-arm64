# v0.23 — Stage 22: first visual renderer milestone

Stage 21 / v0.22.2 proved a complete Level1 victory on ARM64.

Stage 22 adds a visual layer without changing gameplay. The ARM64 executable
records a self-contained HTML replay directly from the live reconstructed
Box2D world and original Lua state.

The viewer contains:
- every real fixture shape (circle/polygon);
- every live body's position and rotation;
- object destruction as bodies disappear;
- score and birdsShot;
- current/flying bird state;
- trajectory trail;
- timeline scrubber;
- 0.5x / 1x / 2x / 4x playback;
- optional object labels;
- the original `levelCompleted` terminal overlay.

This is intentionally a **debug geometry renderer**, not yet the original PVR
sprite renderer. The simple colors/bird/pig decoration are visualization only;
the geometry and motion come from the actual reconstructed gameplay runtime.

Why this first: it gives the next sprite/camera renderer pass a visual oracle.
We can compare sprite transforms against known-good Box2D transforms instead
of debugging graphics and gameplay at the same time.

Run:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-stage22-visual-replay-android-arm64.ps1
```

On PASS the script pulls:

```text
stage22-output\angry-stage22-level1-replay.html
```

and opens it in the default browser.
