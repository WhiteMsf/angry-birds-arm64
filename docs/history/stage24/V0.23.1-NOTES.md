# v0.23.1 — compile-order fix only

The first v0.23 build failed at:

```text
stage22_visual_replay.cpp:2553:13:
error: use of undeclared identifier 'get_global_number'
```

`Stage22ReplayWriter` was inserted earlier in the translation unit than the
existing forward declaration of `get_global_number()`.

v0.23.1 adds the same forward declaration immediately before the Stage 22
replay writer:

```cpp
static double get_global_number(lua_State* L, const char* name);
```

No gameplay, renderer behavior, Box2D state, Lua state, input timing, damage,
camera, or replay format was changed.
