# v0.24.4 — Stage 23.3 GLES1 pbuffer notes

- Promotes the Stage 23.2 static ARMv7 renderer finding (`libGLESv1_CM.so`, fixed-function imports) into a real native ARM64 GPU test.
- Uses the original `INGAME_BIRDS_1.pvr` bytes from the extracted APK; no PNG or RGBA8888 conversion is used for upload.
- Upload contract remains PVR v2 `GL_RGBA_4444` / `GL_UNSIGNED_SHORT_4_4_4_4`.
- Sets `GL_UNPACK_ALIGNMENT=2` because the 1015-pixel atlas has a 2030-byte packed row.
- Renders exact `BIRD_RED` SPRT rect `(182,463 46x45)` with fixed-function client arrays.
- Uses an EGL pbuffer so the GPU path can be proven before Android Activity/JNI/window lifecycle is introduced.
- Performs GPU readback vs CPU-decoded original crop and fails on any >1 channel mismatch.
- Writes a zoomed BMP preview pulled from the device.

This stage is a fidelity gate, not a replacement renderer. Exact original sampler state, blend state, matrix/camera behavior, draw order and lifecycle remain subsequent work.
