# v0.24.5 — Stage 23.4 GLES1 state audit notes

- Stage 23.3 passed on the user's modern ARM64 Android device with exact GPU
  readback: `mismatchPixels(gt1)=0`, `maxChannelError=0`, `totalAbsError=0`.
- The original ARMv7 binary imports `libGLESv1_CM.so`, not `libGLESv2.so`.
- Stage 23.4 deliberately pauses visual implementation to recover fixed-function
  state from the original ARMv7 callsites instead of selecting visually plausible
  modern defaults.
- The audit records texture parameters, blending, alpha test, matrix setup,
  enable/disable state, client arrays, viewport/scissor and draw calls.
- Enum detection in the report is advisory; raw disassembly context remains the
  fidelity source of truth.
- No gameplay or physics code is changed by this version.
