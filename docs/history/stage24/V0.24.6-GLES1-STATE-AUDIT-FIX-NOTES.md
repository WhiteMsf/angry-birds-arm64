# v0.24.6 — Stage 23.4 GLES1 state-audit scanner fix

This revision fixes a false-negative gate in v0.24.5.

## Why v0.24.5 failed

The original ARMv7 binary imports `glVertexPointer` and `glTexCoordPointer`, but the first scanner only recognized `bl`/`blx` textual callsites and then incorrectly required those two client-array functions to have direct callsites. ARM/Thumb wrappers may use tail branches (`b`/`b.w`) or otherwise route through wrappers/PLT.

## Changes

- recognizes `b`, `b.w`, `bl`, and `blx` symbol branches;
- treats `glVertexPointer` and `glTexCoordPointer` as **required imports**, not required argument-bearing direct state callsites;
- keeps hard direct-callsite gates for `glTexParameteri`, `glBlendFunc`, and `glMatrixMode`, because Stage 23.4 needs their argument context to recover renderer state;
- records imported GL functions that still have no recognized direct branch as diagnostics instead of falsely failing.

No renderer behavior or gameplay code is changed. This is only a static-audit harness correction.
