# v0.25.0

Stage 23.6C promotes original native object ordering into the ARM64 renderer audit path.

Key change: `std::map` / object-name ordering is no longer used for GLES object submission. The renderer follows the recovered KA3D Hashtable iterator and the ARMv7 `GameLua::drawGame()` pass predicates.

This version also restores native `setSprite` state tracking, which is required for future live animation fidelity.
