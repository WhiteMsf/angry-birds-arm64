# v0.25.2 — Stage 23.6C numeric branch-target audit fix

No gameplay, renderer, camera, physics, Lua, atlas, or draw-order behavior changed from v0.25.1.

The ARMv7 static audit no longer regex-matches a callee address inside llvm-objdump text. It parses every direct `b` / `b.w` / `bl` / `blx` target in `GameLua::drawGame()` as a numeric address, normalizes the Thumb low bit, resolves the required callee symbols from the same ELF, and compares addresses numerically.

This fixes an llvm-objdump presentation false negative for `Particles::draw(gr::Context*)` at `0x00060f04`.
