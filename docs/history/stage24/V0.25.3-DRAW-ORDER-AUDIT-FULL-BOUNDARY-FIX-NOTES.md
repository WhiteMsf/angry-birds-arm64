# v0.25.3 — Stage 23.6C full-function boundary audit fix

No gameplay, renderer, camera, physics, Lua, atlas, or draw-order behavior changed from v0.25.2.

The previous audit used `llvm-objdump --disassemble-symbols=GameLua::drawGame`, which can stop at the ELF symbol-size boundary before the real tail of this function. On the original Angry Birds 1.4.2 ARMv7 library that truncated view omitted the call at `0x531e8 -> 0x60f04` to `Particles::draw(gr::Context*)`, even though the full disassembly shows the call and the next function header does not begin until `0x5333c`.

Stage 23.6C now performs a full `llvm-objdump -d` of the original library and slices `GameLua::drawGame()` from its exact symbol header to the next function symbol header. Direct branch targets are then parsed numerically from that complete slice. `MaskedImage::render()` and `Particles::draw(gr::Context*)` remain strict required callees; the gate has not been weakened.
