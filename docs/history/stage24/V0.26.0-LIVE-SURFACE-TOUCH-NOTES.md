# v0.26.0 notes

- Stage 23.6C is closed: KA3D Hashtable iteration and the recovered ARMv7
  multipass draw predicates passed on-device, including legitimate overlap
  where total draw calls exceed unique RenderObjectData entries.
- Adds `stage24_live_surface.cpp` as a NativeActivity shared-library target.
- EGL uses `EGL_WINDOW_BIT` + `eglCreateWindowSurface` over `ANativeWindow`.
- A centered 480x320 logical viewport is fitted into the actual Surface size.
- The scene is rendered and `eglSwapBuffers()` is called every game frame.
- Native-app-glue MotionEvents replace the scripted three-shot input harness.
- APK construction is Gradle-free and happens locally with Android build-tools;
  original assets are copied from `~/Downloads/angry-re` only at build time.
- No original Angry Birds assets are shipped in this bootstrap ZIP.
- Adds post-update live state transition logging (`selectedBird`, `flyingBird`,
  `birdsShot`, rubber-band length, score, completion) so real-touch routing can
  be proven without relying on the old scripted sling harness.
- Native stdout is line-buffered and the smoke APK is debuggable so logs can be
  pulled while the activity is still running.
