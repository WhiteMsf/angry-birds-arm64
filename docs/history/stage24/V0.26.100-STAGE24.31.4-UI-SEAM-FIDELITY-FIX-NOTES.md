# v0.26.100 — Stage 24.31.4 UI Seam Fidelity Fix

## Evidence from Stage 24.31.3

Runtime telemetry plus user screenshots reproduced straight horizontal/vertical
lines across the restored tutorial popup and Episode Selection cards. The
renderer showed that many box pieces are atlas strips only one texel thick
(e.g. 1x1 centers and Nx1 edges) stretched to large target rectangles while
`GL_LINEAR` samples exact sprite-rectangle edges.

That means the edge samples can blend with neighboring atlas texels. This is a
renderer-level seam, not a tutorial- or episode-specific asset bug.

## Change

For **target-sized** `Resources::drawSprite` calls only, UV coordinates now run
from the center of the first source texel to the center of the last source
texel:

- `(x + 0.5) / atlasWidth`
- `(y + 0.5) / atlasHeight`
- `(x + width - 0.5) / atlasWidth`
- `(y + height - 0.5) / atlasHeight`

`GL_LINEAR` is preserved. Geometry, anchors, pivots, render-state transforms,
and natural-size sprite UVs are unchanged in this stage.

## Deliberately deferred

The Main Menu settings gear and About/Credits Golden Egg aura have separate
transform/pivot evidence from Stage 24.31.3 and are not modified here. Keeping
this stage seam-only makes the visual result attributable to one renderer
change.
