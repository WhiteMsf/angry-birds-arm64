# v0.26.102 — Stage 24.31.4b Original Texture Sampling / Backing Contract Audit

This is a read-only ARMv7 backend audit. It intentionally does **not** choose a new UI seam fix.

Stage 24.31.4a recovered the important part of `gr::EGL_Image::draw(Context*, float, float, int, int, int, int, float, float)`: the source rectangle is normalized edge-to-edge against the width/height of the texture object held by the image. There is no `+0.5/-0.5` term in that UV construction, and `EGL_RenderBatcher` copies the generated `float2` coordinates rather than adding a later half-texel correction.

Therefore the Stage 24.31.4 ARM64 center-sampling branch remains only an A/B experiment. Its partial visual improvement is evidence of sampling bleed, not evidence that it matches the original renderer.

24.31.4b audits the two architectural facts required before a canonical rewrite:

- the untouched ARMv7 `glTexParameteri` / sampler state used by sprite-sheet textures (MIN/MAG and wrapping);
- the `EGL_Texture` allocation and width/height semantics used as `EGL_Image::draw`'s UV denominator, including whether the backing is logical-size, padded, or power-of-two.

The auditor indexes all original GL texture API callsites, reports their enclosing functions and instruction windows, and dumps the relevant `EGL_Texture`, `EGL_Image` constructor, and texture-creation bodies. No Rovio payload is included in this package.
