# v0.26.103 — Stage 24.31.4c Original EGL_Image POT Backing Reconstruction

This stage replaces the Stage24.31.4 half-texel A/B experiment with the renderer architecture recovered from the untouched ARMv7 binary.

## Recovered ARMv7 contract

- `gr::EGL_Image::EGL_Image(...)` stores the requested logical image width/height, then rounds **each dimension independently** to the next power of two before calling the Context texture factory.
- `gr::EGL_Texture::width()/height()` return those physical backing dimensions.
- integer-subrect `gr::EGL_Image::draw(...)` keeps **edge-to-edge** UVs: `src / textureBacking` through `(src+size) / textureBacking`; there is no +0.5/-0.5 inset.
- `EGL_Texture::allocate()` sets MAG=`GL_LINEAR`; MIN=`GL_LINEAR` unless the supplied additional mip count is the complete chain, in which case MIN=`GL_LINEAR_MIPMAP_NEAREST`.
- ordinary fresh textures retain the GLES default wrap mode; the old ARM64 global `CLAMP_TO_EDGE` allocation choice was not the recovered ordinary sprite-sheet allocation contract.
- raw image upload follows allocate-then-blt semantics: allocate the physical backing, then upload the logical image rectangle at (0,0).

## ARM64 reconstruction

- `Stage235PvrAtlas` now separates logical `width/height` from `backingWidth/backingHeight`.
- PVR and ABR8/PNG transports compute the exact next-POT backing used by the ARMv7 constructor.
- raw RGBA8/RGBA4444/RGB565 textures allocate POT storage and upload only their logical pixel rectangle.
- sprite-sheet, menu, font, scene and ordinary gameplay sprite UVs normalize against the physical backing.
- the old `STAGE24314_APPLY_HALF_TEXEL_FIX` path is disabled.
- ETC1 remains fail-closed if a future corpus provides a non-POT compressed source, rather than inventing a recompression path.
