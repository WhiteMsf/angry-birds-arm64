# v0.26.104 — Stage 24.31.4d Original Atlas / Blit / Blend Contract Audit

Read-only follow-up to the canonical POT-backing reconstruction.

The v0.26.103 runtime proved that the recovered ARMv7 physical POT backing,
edge-to-edge UV normalization, LINEAR sampler and REPEAT wrap are active with
no GL errors, while the user still observes UI seams. Therefore POT backing is
real engine architecture but not sufficient to explain seam-free vanilla UI.

This pass intentionally chooses no visual fix. It gathers the remaining
architectural evidence:

- exact ARMv7 `SpriteSheet::drawSprite` source-rectangle delegation;
- `EGL_Image::blt` and `EGL_Texture::blt` bodies / format conversion path;
- GL blend/alpha state callsites;
- untouched atlas pixels one texel outside the exact UI SPRT rectangles for
  episode boxes, score boxes, slider boxes, tutorial sprites and play-button
  strips, testing both possible DAT Y origins;
- whether those borders are extruded copies, transparent padding, or adjacent
  unrelated pixels.

No Rovio asset bytes are emitted into the report or package; only numeric edge
statistics and disassembly provenance are recorded.
