# v0.26.106 — Stage 24.31.4f Composited Modern Presentation

## Proven cause

Stage 24.31.4e was the decisive A/B test. With the original renderer forced to a literal 854x480 physical raster (1 logical pixel = 1 framebuffer pixel), the straight UI seam artifacts disappeared.

Earlier audits had already recovered the original ARMv7 contracts:

- `EGL_Image::draw` uses edge-to-edge source UVs (no legacy half-texel inset);
- UV normalization uses the physical next-power-of-two `EGL_Texture` backing;
- ordinary sampling is `GL_LINEAR`;
- the original atlases use directional edge extrusion for 1-pixel stretch pieces, while natural-size corner pieces are not universally extruded.

The remaining divergence was therefore Stage24.20.1 presentation ownership: it scaled the 854x480 logical projection directly into a ~1080-high modern viewport, magnifying every atlas sprite before rasterization. Natural-size UI pieces were consequently linearly resampled across atlas boundaries that were safe only under the original 1:1 raster assumption.

## Architecture in this revision

The legacy game renderer remains untouched in logical/raster semantics:

```text
Lua / GameLua / KA3D
        ↓
logical Context 854x480
        ↓
legacy viewport 854x480 physical pixels (1:1)
        ↓
all original sprites/composites rasterize here
        ↓
finished 854x480 frame
```

A new **outer presentation layer** then handles the modern Android display:

```text
finished legacy frame
        ↓
glCopyTexSubImage2D into presentation-only texture
        ↓
single fullscreen/aspect-fit quad
        ↓
modern ANativeWindow Surface
```

The presentation texture is not part of reconstructed KA3D behavior. It is a compatibility boundary outside the legacy renderer. Its POT padding is protected with a half-texel inset **only on this new presentation texture**, never on original Angry Birds atlases.

## Touch ownership

Touch coordinates now follow the visible output:

```text
physical touch inside final aspect-fit viewport
        ↓
map back to 854x480 logical coordinates
        ↓
untouched Lua/native input semantics
```

Touches in black side mattes remain outside the game viewport.

## Unchanged legacy behavior

This revision does not alter:

- original sprite UV math;
- POT atlas backing;
- `GL_LINEAR` legacy atlas sampling;
- sprite/composprite dimensions or pivots;
- Lua menu layout;
- cutscene/story behavior;
- save/persistence;
- tutorial logic;
- physics/audio/trajectory systems.

The Main Menu settings-gear transform and About Golden-Egg aura remain intentionally deferred to the subsequent menu micro-fidelity pass.
