Tooling-only hotfix. No gameplay, renderer, transform, scoring, assets, Lua, physics, audio, or persistence behavior changes.

## Failure fixed
Windows PowerShell `Compress-Archive` rejected the diagnostic bundle because `stage24.31.4f-composited-presentation-runtime.txt` was present twice in the `$include` list: once through `$ui314f` and once through the retained filename list.

## Fix
The pull helper now canonicalizes all bundle inputs with `Sort-Object -Unique` immediately before `Compress-Archive`. This fixes the observed duplicate and prevents the same tooling failure if another report is retained through two collection paths later.

## Recovery after an already-completed .107 test
No rebuild/reinstall/replay is required. Replace only `pull-stage24-live-log.ps1` in the existing `.107` directory with this version, then run it immediately. The already-running/device-side runtime evidence can be collected without changing the tested binary.
