# v0.26.116 / Stage 24.35.1 — Theme2 scene metadata bootstrap hotfix

The first correct 2-1 (`Level52`) run proved the level itself loads successfully: 51 objects were materialized, the original theme2 table was selected, and `INGAME_PARALLAX_2.pvr` had already been parsed/uploaded to GPU. Rendering then failed before the first gameplay frame because `SpriteDB` could not resolve `BACKGROUND_2_LAYER_2` from `INGAME_PARALLAX_2`.

Root cause: v0.26.115 transported the original `INGAME_PARALLAX_2.dat` into APK assets and included its texture in the scene manifest, but two historical native bootstrap lists still enumerated only `INGAME_SKIES_1.dat`, `INGAME_PARALLAX_1.dat`, and `INGAME_GROUNDS_1.dat`: the Android asset-extraction table and the initial `SpriteDB::loadSheet` scene-metadata list.

This hotfix adds the untouched `INGAME_PARALLAX_2.dat` to those same generic paths. It changes no level data, theme2 values, scene render math, physics, progression, save, score, camera, or Bomb behavior. A new Stage24.35.1 static contract prevents a staged-but-unregistered scene DAT from passing preflight again.
