# v0.26.117 — Stage 24.35.2 — Theme-ground MaskedImage fill generalization

The first v0.26.116 run proved Level52/2-1 fully playable and exposed the next historical reconstruction boundary on Level34/2-2. Level34 creates static terrain objects whose untouched `setTexture()` metadata names `INGAME_THEME_GROUND_2`, while the Stage 24.14 MaskedImage consumer was still hardcoded to accept/bind only `INGAME_THEME_GROUND_1`.

This stage does not special-case Level34. It transports the user's untouched `INGAME_THEME_GROUND_2.pvr`, loads/uploads it beside theme1, and selects the fill atlas from each MaskedImage batch's original `RenderObjectMeta.textureName`. Fill UVs use the selected atlas dimensions. Existing mask sprites remain `GROUND_BLOCK_*` from `INGAME_BLOCKS_1`.

No level Lua, progress, score, physics, camera, Blue, Yellow or Bomb behavior is replaced.
