# v0.26.120 — Stage 24.37.0 — RenderState2D negative-scale re-audit

## Runtime trigger

The v0.26.119 user run validated every transported Poached Eggs level through
2-21 and the stock `theme2Complete` path, but screenshots exposed a persistent
menu-background composition error: `LS_BACKGROUND` covered only one half of the
854x480 raster while the other half showed only `currentMenuPage.bgColor`.

The diagnostic trace proves untouched `drawLevelSelectionBackground()` emits
exactly two target-sized draws:

```text
setRenderState(0,0,-1,1,0)
drawSprite('', 'LS_BACKGROUND', -854,0,'LEFT','TOP',427,480)
setRenderState(0,0, 1,1,0)
drawSprite('', 'LS_BACKGROUND',    0,0,'LEFT','TOP',427,480)
```

The second draw already covers x=0..427. The first is meant to be mirrored into
x=427..854.

## Re-audit result

Stage24.31.5b correctly fixed the earlier rotation/pivot bug by moving
`RenderState2D` consumption back to each image draw, but it interpreted the
scale fields as part of the image-local rotation matrix:

```text
old ARM64 reconstruction:
p = origin + translation + pivot + R * S * (local - pivot)
```

The original ARMv7 `gr::EGL_Image::draw(...)` body shows a different ordering.
It reads the angle matrix from `+0x10..+0x1c`, translation from `+0x20/+0x24`,
scale from `+0x28/+0x2c`, and pivot from `+0x30/+0x34`. It first constructs the
rotated destination coordinate and only then multiplies that screen coordinate
by the scale used during viewport normalization:

```text
recovered ARMv7 semantic:
p = origin + translation + pivot + R(angle) * (local - pivot)
screen = S(scaleX,scaleY) * p
```

For the live LS background call this distinction is decisive:

```text
x=-854, width=427, scaleX=-1
pre-scale x range = -854..-427
post-scale x range =  854..427  => visible right half
```

The old local-scale interpretation produced `-1281..-854`, entirely offscreen.

## Implementation

`stage24315bTransformQuad()` remains the single generic consumer. It now:

1. computes the local corner relative to the original pivot;
2. applies only `R(angle)` locally;
3. adds draw origin + translation + pivot;
4. applies `scaleX/scaleY` to the resulting screen coordinate.

No `LS_BACKGROUND`, page-name, episode-name, or level-name branch is introduced
in the geometry path. A bounded observer logs final bounds for negative-scale
and `LS_BACKGROUND` draws as `[stage24.37.0-renderstate]`.

The historical Stage24.31.5b preflight is updated to reject the old local-scale
ordering, and Stage24.37.0 adds an explicit math proof:

```text
mirrored half => x=427..854
normal half   => x=0..427
union         => x=0..854, y=0..480
```

## Regression scope

The settings gear and Golden Egg aura fixes are preserved structurally: their
critical correction was local pivot rotation, and the common steady-state path
uses scale 1.0. This pass must still be visually checked because menu entrance
animations can use non-unit scale.

Gameplay, Box2D, camera, score, save/progression, audio, scene rendering, terrain
fills, Blue `CLUSTER_BOMB`, Yellow `BOOST`, Bomb `BOMB`, and White
`DROPPABLE_EGG` are unchanged.
