# v0.26.121 — Stage 24.37.0a
## RenderState2D re-audit preflight compatibility hotfix

The first v0.26.120 test never reached compilation or device execution.  The
inherited Stage 24.31.5b static guard failed after Stage 24.37.0 inserted a new
bounded `LS_BACKGROUND`/negative-scale observer earlier in
`stage24132DrawSprite()`.

The runtime implementation itself was not the failing component.  The old
contract sliced only the first 9000 source characters of that function and then
required the older `transformedTL=` / `transformedBR=` telemetry strings to be
inside that slice.  Stage 24.37.0's extra observer pushed those retained strings
past the arbitrary cut, producing a false FAIL even though the new post-affine
screen-scale implementation and legacy telemetry both remain in the source.

Stage 24.37.0a changes only that inherited static guard.  It now accepts either:

- Stage 24.37.0's semantic `bounds=(...)` observer with
  `ARMV7_POST_AFFINE_SCREEN_SCALE`, or
- the retained Stage 24.31.3 transformed-corner telemetry.

All affine-ordering guards, original ARMv7 field evidence, anti-sprite-specific
checks, presentation closure and passive score guards remain intact.

`stage24_live_surface.cpp` is byte-identical to v0.26.120.  Therefore there is
no runtime/gameplay/render change in this hotfix; it only allows the corrected
Stage 24.37.0 runtime to actually build and reach the visual test.

powershell -ExecutionPolicy Bypass -File .\test-stage24-menu-background-renderstate.ps1
