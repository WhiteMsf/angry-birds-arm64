## Joint + bounds/lifecycle contract discovery

The retained Stage24.42.1 partial Danger Above run proves the generic nonlegacy
deferred bird-velocity reconstruction survives beyond the old 6-5 Boomerang
crash and through completed 6-12. The page is not yet fully closed because
6-13..6-15 remain to be completed.

A separate fidelity observation from Mighty Hoax 5-11 is now the next native
contract frontier. A flag-like polygonal piece remains suspended/attached to a
straight support in the original game but falls once physics starts in the
ARM64 port. `createJoint` and `destroyJoint` are still blanket Stage8 stubs.
Untouched `loadLevelInternal` exposes joint records through
`end1/end2/type/coordType/x1/y1/x2/y2`, but the exact native branch semantics
must be recovered before creating any Box2D joint.

Stage24.43.0 therefore remains discovery-only:

- Build-time contract disassembles and preserves the complete ARMv7 bodies of
  `GameLua::createJointLua`, `destroyJointLua`, `setLevelLimits`,
  `setMaxTranslation`, and `setGameOn`.
- Runtime `createJoint`/`destroyJoint` probes log every Lua argument and any
  string argument that resolves to a live Box2D body, including body state.
- `setLevelLimits`, `setMaxTranslation`, and `setGameOn` are instrumented
  observe-only so the next physics/lifecycle pass can recover their exact use.
- No b2Joint is created or destroyed by this stage and there is no 5-11/
  LevelP2_86 special case.
