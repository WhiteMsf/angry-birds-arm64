# v0.26.134 / Stage 24.43.0a — Joint discovery preflight compatibility hotfix

This source release changes no ARM64 runtime behavior. `stage24_live_surface.cpp` is byte-identical to v0.26.133.

The Stage 24.43.0 discovery contract incorrectly searched the source for the literal text `[stage24.43.0-joint] BODY_MATCH`, while the actual generic logger format is `[stage24.43.0-joint] %s BODY_MATCH ...` and emits `CREATE BODY_MATCH` / `DESTROY BODY_MATCH` at runtime. The preflight therefore returned exit 5 before compilation.

The gate now checks the semantic `BODY_MATCH arg=` telemetry token while retaining all observe-only / no-level-hack guards.
