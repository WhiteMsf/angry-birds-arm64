# v0.26.135 / Stage 24.43.1 — Original distance-joint reconstruction

## Discovery trigger

The Stage24.43.0a run reached Danger Above 6-15 (`LevelP3_231`) and exposed a deterministic missing-joint failure stronger than the original 5-11 visual clue. The level calls `createJoint` nine times per load. Every call is `argc=9`, `type=1`, `coordType=2`, with `(x1,y1,x2,y2)=(0,0,0,0)`, and connects a pig body to a static balloon body. The observe-only build created no native joint. Before the first bird was fired, the score climbed from 0 to about 55,920 as the untethered pigs/structure died.

## ARMv7 contract

`GameLua::createJointLua(lua::LuaState*)` compares arg4 exactly with `1.0f`. That branch constructs joint type 3, which is `b2DistanceJointDef` in the pinned Box2D contract. Recovered constants are `collideConnected=false`, `frequencyHz=4.0f`, `dampingRatio=0.5f`. `coordType` is `floor(arg5+0.5)`, default 0.

- coordType 0: zero local anchors; body origins are the metadata/world anchor coordinates; length is origin-to-origin distance.
- coordType 1: args6..9 are world coordinates; original code subtracts body positions to form local anchors; length is world-point distance.
- coordType 2: args6..9 are local anchors; body transforms produce world points; length is their distance.
- other values take no coordinate branch, preserving constructor zero anchors and default length 1.0.

`GameLua::destroyJointLua(lang::String)` searches its native joint record by name and calls `b2World::DestroyJoint`. `createJointLua` also mirrors metadata under `objects.joints[name]` with original keys `name`, `end1`, `end2`, `type`, `coordType`, and physical-path `x1/y1/x2/y2`.

## Implementation policy

No level/object special case. Type 1 is reconstructed generically. Other Lua joint types are not guessed: they keep the original non-CreateJoint branch until live/static evidence requires more. Bounds/lifecycle stubs remain passive.
