# v0.26.137 — Stage 24.44.0a bounds/lifecycle preflight cross-proof hotfix

This release is a tooling-only hotfix over v0.26.136.

The v0.26.136 run reached and passed the dedicated Rovio mutable
`b2_maxTranslation` patch, then the Stage24.44.0 aggregate ownership script
returned exit 6 before native compilation/runtime.

The aggregate script had duplicated brittle textual validation of ARMv7
evidence already proven by the immediately preceding Stage24.43.0 report and
recursively scanned the entire Box2D vendor tree after a dedicated exact patch
had already succeeded.

Stage24.44.0a now:
- consumes the already-PASS Stage24.43.0 report as the authoritative ARMv7
  prerequisite for `setLevelLimits`, `setMaxTranslation`, and `setGameOn`;
- verifies the mutable max-translation pair directly in the exact patched
  `b2Settings.h` / `b2Settings.cpp` files;
- keeps fresh nm/objdump consumer scanning as diagnostic evidence rather than a
  duplicate formatting-sensitive build gate;
- retains hard gates proving `setLevelLimits` and `setGameOn` are observe-only
  and the bounds observer cannot mutate Box2D bodies.

`stage24_live_surface.cpp` is unchanged from v0.26.136.
No gameplay/physics behavior is changed by this hotfix.
