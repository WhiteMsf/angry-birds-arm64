## Theme9 policy
This stage deliberately does **not** hardcode a Theme9 background/parallax/foreground combination.

The existing generic `GameLua::setTheme` reconstruction reads the untouched `blockTable.themes[theme]` at runtime and logs exact colors, background layer tuples and foreground layer tuples. Stage24.46.0 uses that live table as the authority.

The original 1.4.2 asset inventory contains `INGAME_PARALLAX_CRANES.dat/.pvr`, a previously unused scene sheet. It is now transported and loaded into the generic scene SpriteDB as **discovery coverage only**. Its presence is not treated as proof that Theme9 consumes it; the live table must prove that association.

No new terrain-fill name is invented. All eight already-proven original `INGAME_THEME_GROUND_1..8` fills remain available to the generic MaskedImage selector.
