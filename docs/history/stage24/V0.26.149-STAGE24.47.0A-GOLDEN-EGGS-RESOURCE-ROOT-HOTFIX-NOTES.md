# v0.26.149 / Stage24.47.0A — Golden Eggs resource-root hotfix

## Live witness
The first Stage24.47.0 run clicked Golden Eggs slot 11, which the untouched menu resolves to `LevelGE_7`.

The loader received:

`levels/goldeneggs1/LevelGE_7`

while the original APK data tree and Stage24 transport place the file at:

`data/levels/goldeneggs1/LevelGE_7.lua`

The Stage24.47.0 static transport contract passed because the file was correctly staged and listed for extraction, but Stage24.12.8 only searched the Stage24 root directly for relative logical paths. This was sufficient for campaign menus because those already supplied `data/levels/packN/...`; Golden Eggs is the first observed caller whose level folder is relative to the original `data/` resource root.

## Reconstruction
`stage24128_resolve_lua_resource_path()` now adds the generic candidate:

`<Stage24Root>/data/<logical>`

for relative level logical paths beginning with `levels/`.

No `LevelGE_*`, slot, unlock, completion or Golden Egg-specific behavior is hardcoded.

## Expected live proof
A selected Golden Egg should log a resolution like:

`logical='levels/goldeneggs1/LevelGE_7' resolved='.../stage24/data/levels/goldeneggs1/LevelGE_7.lua'`

and proceed into the level chunk. Any subsequent failure is a new Golden Eggs frontier and should be audited independently.
