# v0.26.15.1 / Stage 24.12 — compile-only telemetry helper fix

The first live test of v0.26.15 stopped at C++ compilation before APK install.

`stage24_live_surface.cpp` added Stage 24.12 result-layout telemetry using an accidental helper name:

- `global_table_name(L, "currentMenuPage")`
- `global_table_name(L, "newMenuPage")`

No `global_table_name()` helper exists. The already-existing helper with the intended semantics is:

- `table_field_table_name(L, globalName)`

It reads the global table's `name` field and is already used by the adjacent post-complete/result telemetry.

This patch changes only those four telemetry calls. It does **not** change Lua behavior, font metrics, `clipText`, `prepareMenuPage`, `drawMenu`, physics, rendering, input, or the Stage 24.12 test criteria.
