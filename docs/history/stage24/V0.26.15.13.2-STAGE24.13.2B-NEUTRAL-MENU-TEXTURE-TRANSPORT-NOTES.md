# v0.26.15.13.2 — Stage 24.13.2b — neutral menu texture transport

Live evidence from v0.26.15.13.1 showed that the final APK ZIP contained all 11 menu transport entries (`already=11 injected=0`), yet `AAssetManager_open()` returned null for `stage24/menu-textures/BACKGROUNDS_GE_1.pvr` before the Lua/renderer boot.

This revision changes **only APK transport naming**:

- original PVR bytes are packaged as `<logical>.pvr.bin`; bytes remain byte-identical;
- PNG-derived lossless ABR8 transports are packaged as `<logical>.png.rgba8.bin`;
- `manifest.tsv` still carries the original logical texture name and semantic kind (`pvr4444`/`rgba8`);
- runtime parsing is unchanged and consumes the exact extracted bytes;
- no Lua, physics, input, menu layout, draw order, GL semantics, or font semantics are changed.

The goal is to avoid aapt/AssetManager special handling keyed from the original final extension while preserving original texture content exactly.
