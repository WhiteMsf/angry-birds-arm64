# v0.26.15.4 / Stage 24.12.3 — original font-selection bytecode audit

## Trigger

v0.26.15.3 proved the Stage 24.12.2 `res.releaseSpriteSheet` bridge: the
original `releaseImages()` released all three `SPLASHES_SHEET_*` paths and
advanced into `prepareTextItem()`.

The first remaining divergence is now:

```
res.useFont(nil/"") -> current font remains <none>
prepareTextItem -> clipText(...)
clipText: current bitmap font metrics unavailable for '<none>'
```

Choosing `FONT_BASIC` here without evidence would violate the differential
methodology.  The historical Stage24 path also skipped most of the original
splash/create-assets sequence, so the missing state may be either an omitted
startup selection or a native default-font semantic.

## Change

No runtime semantics are changed.

Before Stage24 replaces any native-bound globals, this build dumps the exact
Lua 5.1 bytecode/constants for these untouched original closures when present:

- `setFont`
- `prepareTextItem`
- `prepareMenuPage`
- `loadFonts`
- `createAssets`

Output prefix:

```
[stage24.12.3-font-audit]
```

The dump is capped at 512 instructions per function and does not execute those
functions. Existing Stage24.12.2 behavior is otherwise unchanged.

## Goal

Use the device's own original 1.4.2 `gamelogic.lua` chunk to determine the
first semantically correct font-selection transition before changing
`res.useFont`, `createBitmapFont`, `clipText`, or bootstrap ordering.
