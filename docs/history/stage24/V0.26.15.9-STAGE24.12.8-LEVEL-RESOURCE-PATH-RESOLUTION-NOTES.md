# v0.26.15.9 — Stage 24.12.8 level resource-path resolution

Live evidence from v0.26.15.8:

- original `loadLevelInternal()` returned normally for the initial absolute `Level1.lua` smoke;
- Level1 reached `updateMenu` / `levelComplete`;
- selecting the result-menu reload path later called native `loadLevel('data/levels/pack1/Level1')`;
- the Stage24 native binding incorrectly passed that logical resource name verbatim to `luaL_loadfile`, producing ENOENT.

This revision reconstructs only that native resource boundary:

- stages the original Level1 at `stage24/data/levels/pack1/Level1.lua` in addition to the legacy smoke location;
- materializes it to `<app-private>/stage24/data/levels/pack1/Level1.lua`;
- `loadLevel` preserves already-existing paths, otherwise resolves logical paths below the Stage24 app-private root;
- a missing `.lua` suffix is appended by the native resource boundary;
- telemetry prints both logical and resolved paths.

No Lua menu behavior, Box2D behavior, rendering, input, font metrics, composprite bounds, save/highscore semantics, or drawMenu behavior is changed.
