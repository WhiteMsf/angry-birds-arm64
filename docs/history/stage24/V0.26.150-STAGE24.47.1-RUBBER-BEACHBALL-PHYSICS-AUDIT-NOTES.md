# v0.26.150 / Stage24.47.1 — rubber / beachball physics audit

## Why this stage exists

The Golden Eggs resource-root hotfix is live-clean: playable Golden Egg Lua chunks now resolve under the original `data/` resource root, and the latest device run contains no Lua/GPU/native fatal marker from that fix.

The user also re-raised a known physics-fidelity debt that predates Golden Eggs. The same visibly wrong "bouncy" behavior is reproducible in:

- Golden Egg 2 (`LevelGE_2`)
- Danger Above 8-3 (`LevelP3_306`)

The relevant Golden Egg 2 objects are `ExtraRubberBall_*`, rendered as `BLOCK_BEACHBALL`, with untouched Lua material `rubber`.

This stage intentionally **does not tune physics**. Existing ARMv7 audits already prove the high-level construction/material rules strongly enough that an ad-hoc restitution tweak would be a regression risk.

## Existing original contracts retained

The build still runs the earlier ARMv7 audits proving:

- `GameLua::createCircle/createBox` pass density, friction and restitution directly into Box2D.
- dynamic bodies use the recovered body defaults, including angular damping `1.0`.
- contact friction mix is `sqrt(fA*fB)`.
- contact restitution mix is `max(rA,rB)`.
- restitution velocity threshold remains `1.0`.
- recovered Rovio tolerance differences remain active (`b2_linearSlop=0.05`, sleep constants, polygon radius coherence).
- Rovio's mutable `b2_maxTranslation` + squared companion remain reconstructed.
- fixed stepping remains the ARMv7-recovered `world.Step(dt, 10, 10)` path.

No one of those is changed by Stage24.47.1.

## New read-only witness

Every contact involving untouched Lua `material='rubber'` may now emit:

- `[stage24.47.1-rubber] BEGIN`
  - exact level and pair
  - world contact point + normal
  - both body masses/inertias
  - both linear/angular velocities before solver
  - fixture and Lua friction/restitution
  - exact stock/Rovio effective mixed friction/restitution
  - relative normal approach velocity
- `[stage24.47.1-rubber] SOLVER`
  - first normal/tangent solver impulse
  - immediate post-solver body velocities
  - per-body translation candidate for the current fixed dt
  - whether that candidate crosses the reconstructed mutable `b2_maxTranslation`
- `[stage24.47.1-rubber] AFTER`
  - post-`world.Step` linear/angular velocities
  - pre/post relative normal velocity

Ambient rubber contacts are capped separately from bird/rubber contacts so Golden Egg 2's falling beachballs cannot exhaust the useful bird-impact telemetry.

The observer writes no body, fixture, contact, Lua, score, save, completion or unlock state.
