# v0.26.156 / Stage24.47.6A — Native JNI lifecycle audit hotfix

This is a tooling-only hotfix on top of v0.26.155 / Stage24.47.6.

The lifecycle implementation is unchanged. The 47.6 ARMv7 JNI acquisition script previously read only the ordinary symbol table with `llvm-nm -S`. On the user NDK/toolchain, the JNI entrypoints are exposed through the dynamic symbol table, even though older Stage24.16.4 diagnostics already prove the exact symbols exist.

The audit now merges `llvm-nm -S -C` and `llvm-nm -D -S -C`, matching the robust strategy already used by prior native audits. It still fails closed if any of the four original entrypoints are actually absent.

Expected original JNI witnesses:
- `Java_com_rovio_ka3d_MyRenderer_nativePause`
- `Java_com_rovio_ka3d_MyRenderer_nativeResume`
- `Java_com_rovio_ka3d_MyRenderer_nativeDeinit`
- `Java_com_rovio_ka3d_MyRenderer_nativeInit`

No gameplay, Box2D, renderer, audio, save, Golden Egg, or lifecycle runtime semantics were changed by this hotfix.
