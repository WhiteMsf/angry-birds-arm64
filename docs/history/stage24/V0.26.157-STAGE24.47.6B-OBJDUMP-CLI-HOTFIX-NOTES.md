# v0.26.157 / Stage24.47.6B — llvm-objdump lifecycle auditor hotfix

Tooling-only hotfix on top of v0.26.156. The Android lifecycle implementation is unchanged.

The 47.6 JNI acquisition auditor was the only Stage24 native auditor invoking llvm-objdump as separate `--start-address VALUE` / `--stop-address VALUE` arguments. The user's NDK tooling is already proven by earlier Stage24 audits with the canonical `--start-address=0x...` / `--stop-address=0x...` form.

47.6B now:
- uses the same equals-form range syntax as the established native auditors;
- passes `--demangle` consistently;
- prefers text/nonzero-size duplicate symbols when `.symtab` and `.dynsym` both expose a JNI entry;
- falls back to one full disassembly and function extraction if range options still fail;
- remains fail-closed if any of nativeInit/nativePause/nativeResume/nativeDeinit cannot actually be acquired.

No gameplay, Box2D, renderer, audio, save, Golden Egg, or lifecycle runtime semantics changed.
