# v0.26.159 — Stage24.48.1 Release Branding Cleanup

## Scope
Packaging-only cleanup. No gameplay, Box2D, Lua, renderer, audio, lifecycle or input semantics are changed.

## Changes
- application label is exactly `Angry Birds`;
- manifest launcher icon is `@drawable/app_icon`;
- development version metadata is synchronized to `versionName=0.26.159`, `versionCode=26159`;
- build creates a temporary Android `res/drawable` tree and locates the original launcher PNG from the user's local `angry-re` extraction or original Angry/Rovio APK;
- proprietary launcher art is not shipped in the source ZIP;
- `aapt package` now includes the generated `res` tree;
- post-package badging audit fails closed unless the APK reports label `Angry Birds` and `res/drawable/app_icon.png`;
- focused launcher test sends the device Home after install for a human name/icon check.

## Frozen engine baseline
`stage24_live_surface.cpp` and `CMakeLists.txt` remain identical to v0.26.157 / Stage24.47.6B. Stage24.48.0 was adjusted so its baseline hash gate covers engine files rather than the intentionally mutable release-envelope manifest.
