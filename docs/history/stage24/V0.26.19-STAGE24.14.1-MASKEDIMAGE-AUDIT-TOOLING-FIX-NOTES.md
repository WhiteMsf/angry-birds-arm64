# v0.26.19 — Stage 24.14.1 MaskedImage audit tooling fix

This revision changes only the optional ARMv7 static-audit tooling.

The previous build selected `_ZN11MaskedImage6renderEv` from `llvm-nm` and then
asked `llvm-objdump --disassemble-symbols` to resolve that name.  On the old
ARMv7 `libangrybirds.so`, llvm-objdump rejected the symbol and PowerShell's
error policy aborted the build before compilation.

v0.26.19 now:

- runs `llvm-nm -S -C` and searches the demangled `MaskedImage::render` candidates;
- keeps every matching overload/candidate instead of assuming one mangled name;
- parses each candidate's address and size;
- clears the Thumb address bit when necessary;
- disassembles with `--start-address/--stop-address`, avoiding local-symbol lookup;
- isolates native-tool stderr/nonzero exits so a stripped or unusual ARMv7 library
  can never abort the actual ARM64 build;
- leaves the Stage 24.14.1 live MaskedImage/setTexture audit and strict renderer
  gate unchanged.

No Lua, physics, input, renderer, Level57, menu, font, particle, or gameplay
semantics changed in this revision.
