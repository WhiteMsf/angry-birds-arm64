# v0.26.2 notes

- Fixes the Stage 24 APK-packaging failure on Windows user profiles containing non-ASCII characters.
- The native ARM64 library already built and linked successfully in v0.26.1; the failure occurred later when legacy `aapt`/`ziparchive` tried to open `android.jar` through the Unicode SDK path.
- The build script now temporarily maps `%USERPROFILE%` to a free ASCII-only DOS drive using `subst.exe` and passes mapped paths to `aapt`, `zipalign`, `apksigner`, and `adb install`.
- The mapping is released after installation (and on the explicit aapt/install failure paths).
- No gameplay, Lua, Box2D, camera, renderer, draw-order, touch mapping, or asset logic changed.
- Smoke APK version is now 0.26.2 / versionCode 2602.
