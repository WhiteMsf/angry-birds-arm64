# v0.26.23 — Stage 24.14.4 — exact ETC1 PVR terrain fill

Concrete live evidence from v0.26.22.1 showed `INGAME_THEME_GROUND_1.pvr` is not RGBA4444:

- PVR v2 header length 52
- 256x256
- pixel type low byte `0x36`
- 4 bpp
- 8 additional mip levels (9 total)
- payload 43704 bytes
- RGB masks `0xffffffff`, alpha mask `0`

43704 bytes exactly equals an ETC1 4x4-block mip chain from 256x256 through 1x1, including one 8-byte block for the 2x2 and 1x1 tail levels.

This revision adds only that evidenced texture contract. RGBA4444 remains unchanged. ETC1 is uploaded with `GL_ETC1_RGB8_OES` when `GL_OES_compressed_ETC1_RGB8_texture` is advertised. If the device lacks that extension, Level1 remains bootable and failure is deferred to the first MaskedImage draw.

No MaskedImage geometry, UV, texture-combine, physics, Lua, camera, menu, font, or progression semantics are changed.
