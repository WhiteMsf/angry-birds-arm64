# v0.26.24 — Stage 24.14.5 — original alpha-mask fidelity

## Scope

This build changes exactly one visible MaskedImage semantic and adds nonfatal evidence collection for the remaining terrain seam/alignment work.

No gameplay physics, camera, object transforms, sprite pivots, mask UV coordinates, fill UV coordinates, draw order, or Level57 progression values are changed.

## Proven divergence fixed

Stage 24.14.4 used GLES1 texture-unit 1 as an RGBA modulation:

- RGB = fill RGB * mask RGB
- alpha = fill alpha * mask alpha

That was an approximation.

Two independent Angry Birds/Rovio-era shader trees use the alpha-masked 2D contract in which the base texture supplies the color and the second texture contributes only its alpha mask. Stage 24.14.5 reproduces that contract with GLES1 combiners:

- RGB = fill RGB unchanged
- alpha = fill alpha * mask alpha
- blending remains SRC_ALPHA / ONE_MINUS_SRC_ALPHA

The mask's RGB channels are intentionally ignored.

- Assasain20/AngrySDK, commit a54d15d08fa308f2cafa3473aea09ca82e363d81:
  - data/shaders/gl2/2d-sprite-alpha-masked.fx
  - data/shaders/gl2/pixelShaders/pp.ps
  - data/shaders/gl2/commons/uniforms.sh
- elias10escoficial123-gif/Source-Code-Angry-Birds-samsung-smart-tv, commit 5087e3f9ce5514bbe4da0f95ebb7293e16621c97:
  - 2d-sprite-alpha-masked.fx
  - pp.ps

These later/platform-adjacent sources are corroboration, not a replacement for the exact Android 1.4.2 binary. The build therefore also searches the user's own angry-re tree for matching shader-source evidence and records hashes/lines when present.

## No magic-number seam fix

The visible joint/edge mismatch in Level57 is not patched by eye.

The recovered Android ARMv7 MaskedImage::add() derives mask UV bounds from the sprite's actual atlas position/size and sheet image dimensions. Stage 24.14.5 leaves those values untouched; there is no invented half-texel inset or pixel nudge.

The build adds `stage24.14.5-original-mask-fidelity.txt`, which attempts to recover:

1. any matching alpha-mask shader source in the user's original extracted tree;
2. the exact .rodata window referenced by MaskedImage::render();
3. every ARMv7 call site of MaskedImage::add(), capturing the complete containing function so the producer's model/x/y setup can be reconstructed without guessed offsets.
