# v0.26.25 — Stage 24.14.6 — per-level native scene lifecycle

## First concrete divergence
After original Next Level changes `Level1 -> Level57`, the untouched Lua loader creates the new level state, but the reconstructed native `PhysicsBridge` kept previous-level Box2D bodies and render metadata alive. Only same-name objects were replaced by `createBox/createCircle`; unique Level1 objects therefore remained visible/physical in 1-2. A later collision could reach original Lua with a native body whose entry no longer existed in the fresh Lua `objects.world`, producing `attempt to index a nil value`.

## Reconstructed semantic boundary
Each successful `loadLevel()` now retires the previous level's native scene before the new level's `createBox/createCircle` materialization:

- destroy every old Box2D body;
- clear the native name -> body map;
- clear RenderObjectData transform/meta ownership;
- reset the KA3D Hashtable draw-order model to an empty table;
- reset per-level render interpolation index/alpha and creation ordinal.

No resource atlas, sprite metadata, fonts, menus, Lua globals, texture contracts, camera constants, UVs, pivots, physics constants or terrain geometry are modified.

This is lifecycle reconstruction, not name-based cleanup: no Level1 object list or numeric threshold is used.

## Expected trace
Initial boot should report an empty reset. On 1-1 -> Next -> 1-2, the Level57 load should report nonzero retired state, e.g.:

```
[stage24.14.6-lifecycle] native level scene reset logical='data/levels/pack1/Level57' bodies=... transforms=... renderMeta=... renderOrder=...
```

The visible test is that no surviving 1-1 objects remain in 1-2. The former stale-body `blockCollision ... attempt to index a nil value` should also disappear if it had the same lifecycle cause.
