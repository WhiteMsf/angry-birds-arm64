# v0.26.26 — Stage 24.15.0

This revision deliberately stops progression at the already-proven 1-1 -> 1-2 boundary and starts reconstruction of the missing gameplay scene presentation.

No visual behavior is changed yet. The build inventories the user's exact 1.4.2 `INGAME_SKIES_*`, `INGAME_PARALLAX_*`, `INGAME_GROUNDS_*`, and `INGAME_THEME_GROUND_*` files, records raw PVR v2 headers and scene-related DAT strings, and inspects Level1/Level57 scene strings. Runtime telemetry records the untouched level environment's `theme`, `themeSprites`, `physicsToWorld`, gravity and water level before native materialization.

The pull script is concise by default. Full logcat and static ARMv7 audits stay on disk and are printed only with `-Full`.

No magic-number positioning, no background approximation, no extra levels.
