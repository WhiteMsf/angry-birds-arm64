# v0.26.27 — Stage 24.15.0 diagnostic bundle tooling

No game/runtime semantic changes from v0.26.26.

The default pull workflow no longer prints historical audits or log tails to the terminal.
`pull-stage24-live-log.ps1` now captures the three live logs, creates `stage24-summary.txt`, includes existing static audit reports when present, and compresses everything into:

`stage24-output/stage24-diagnostics.zip`

Upload that ZIP for analysis. `-Full` prints only the compact summary, never the multi-thousand-line raw reports.
