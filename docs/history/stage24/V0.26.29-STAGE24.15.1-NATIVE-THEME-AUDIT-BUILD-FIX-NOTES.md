# v0.26.29 / Stage 24.15.1

## Native theme audit compile-order fix

This revision changes no game semantics.

The Stage 24.15.1 `setTheme` telemetry wrapper referenced `get_global_string()` and `get_global_number()` before their declarations in the translation unit. Clang therefore rejected `stage24_live_surface.cpp` before the runtime could start.

This revision adds forward declarations for those two already-existing helpers before `l_stage24151_setTheme_audit()`. Their implementations are unchanged.

The ARMv7 theme/native static audit, scene assets, physics, renderer, MaskedImage, Lua, lifecycle, menu, and progression behavior are otherwise identical to v0.26.28.
