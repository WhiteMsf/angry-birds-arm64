# v0.26.3 notes — recovered ARMv7 gravity

The first live Stage 24 APK made a remaining physics mismatch perceptible when compared with footage of Angry Birds Classic 1.4.2: flight/fall motion looked too light.

Re-auditing the original ARMv7 `GameLua` constructor showed the exact world-gravity vector passed to `b2World`:

- first float literal: `0x00000000` = `0.0f`;
- second float literal: `0x41a00000` = `20.0f`;
- those two values are written contiguously and passed by address to `b2World(b2Vec2 const&, bool)`.

Therefore the recovered original gravity is **`(0.0f, 20.0f)`**, not the provisional `(0.0f, 10.0f)` used by the reconstruction through v0.26.2.

Changes in v0.26.3:

- Stage 24 live `PhysicsBridge` now constructs Box2D with `(0,20)`;
- runtime log emits `Recovered ARMv7 world gravity active: (0.000000,20.000000)`;
- APK version becomes 0.26.3 / versionCode 2603;
- prior Stage 22.7 frame/timing corpus is explicitly marked provisional because it was generated with the wrong gravity.

No renderer, camera, KA3D draw-order, input, APK packaging, or GLES state logic changed.
