# v0.26.31 / Stage 24.15.3 — original theme1 scene renderer

This patch implements the first real global gameplay scenery path for the native ARM64 port.

## Evidence used

The running original 1.4.2 `blocks.lua` table reports for `theme1`:

- `color = RGB(148,206,222)`
- `groundColor = RGB(10,19,57)`
- background 1: `INGAME_SKIES_1 / BACKGROUND_1_LAYER_1`, parallax `0.125`, scale `2`
- background 2: `INGAME_PARALLAX_1 / BACKGROUND_1_LAYER_2`, parallax `0.5`, scale `2`
- background 3: `INGAME_PARALLAX_1 / BACKGROUND_1_LAYER_3`, parallax `1`, scale `1.5`
- foreground 1: `INGAME_GROUNDS_1 / FOREGROUND_1_LAYER_1`
- foreground 2: `INGAME_PARALLAX_1 / FOREGROUND_1_LAYER_2`

The original ARMv7 `GameLua::setTheme(lang::String)` provides the missing background defaults:

- slot 3 default `1.0`
- slot 4 default `1.0`
- slot 5 default `true` (horizontal repeat)
- slot 6 default `4.0` (non-repeat offset)

For theme1, slot 5/6 are nil in Lua, therefore all three backgrounds use the original repeat=true default. The non-repeating draw branch is intentionally not reconstructed by this patch and remains a strict future boundary.

## Original native drawing semantics reconstructed

`GameLua::drawBackground()` (`0x4fc58..0x4ffbc`) provides:

- theme background color -> native background clear
- per-layer `layerScale * worldScale`
- vertical camera transform `-topLeftY / layerScale`
- horizontal phase from `fmod(topLeftX * parallax, spriteWidth * layerScale)`
- `__fixsfsi` truncation toward zero for the first repeated sprite
- sprite pivot anchor from the original DAT
- repeat until native context width is covered

`GameLua::drawForegroundNative()` (`0x4e738..0x4ea64`) provides:

- `groundColor / 255`
- first foreground `(height - pivotY)` determines the solid lower-ground rectangle
- exact foreground scale constant `1.5`
- horizontal phase from `fmod(topLeftX, spriteWidth * 1.5)`
- the same truncation/pivot/repeat structure as the original

No visual constants are fitted from screenshots.

## Exact original assets staged

- `INGAME_SKIES_1.dat` + `INGAME_SKIES_1.pvr`
- `INGAME_PARALLAX_1.dat` + `INGAME_PARALLAX_1.pvr`

- ETC1 PVR v2 for skies/grounds
- RGBA4444 PVR v2 for parallax

## Rendering order

1. exact theme background clear
2. three original background/parallax layers
3. existing native gameplay object / MaskedImage passes
4. original ground-color rectangle
5. two original foreground layers
6. existing LevelComplete/menu rendering
