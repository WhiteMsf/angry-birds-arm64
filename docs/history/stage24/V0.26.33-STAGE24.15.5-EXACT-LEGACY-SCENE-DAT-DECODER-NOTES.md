# v0.26.33 — Stage 24.15.5

## First proven divergence
Stage24.15.3 black-screened because `SpriteDB::loadSheet()` assumed every sprite DAT contained a `SPRT` chunk. Stage24.15.4 exact-byte audit proved the 1.4.2 files use two formats in the same theme:

- `INGAME_PARALLAX_1.dat`: normal `KA3D` / `SPRT` container.
- `INGAME_SKIES_1.dat` and `INGAME_GROUNDS_1.dat`: headerless single-texture sprite payload.

The headerless grammar is exact and size-closing:

```text
str16(textureName)
u16 spriteCount
repeat spriteCount times:
    str16(spriteName)
    i16 x
    i16 y
    i16 width
    i16 height
    i16 pivotX
    i16 pivotY
EOF
```

For the audited originals, that grammar consumes exactly 392/392 bytes for skies and 542/542 bytes for grounds.

## Change
`SpriteDB::loadSheet()` now accepts this second exact grammar only when the entire input parses with no trailing bytes. Parsed rects and pivots are committed only after full validation. Normal `SPRT` behavior is unchanged.

Once all three original scene metadata files parse, the Stage24.15.3 theme1 scene renderer is re-enabled.

## Non-changes
No camera, physics, MaskedImage, menu, font, progression, UV, parallax, or sprite-position tuning. No magic numbers were added.
