# v0.26.49 — Stage 24.20.1 Debug Display Harness

This stage adds a **testing-only** era-appropriate WVGA presentation mode. It does not redefine vanilla 1.4.2 behavior.

Default build mode (`wvga854`):
- logical Context exposed to Lua/camera/input: **854x480**
- physical ANativeWindow remains the device Surface
- logical output is uniformly scaled and centered
- unused physical area is cleared black by the harness
- touch is mapped from the centered physical viewport back to 854x480
- menus and gameplay share the same debug logical Context
- because screenHeight=480, original Android selectors still choose the recovered 864x480 asset/font bucket

Native comparison mode:
```powershell
powershell -ExecutionPolicy Bypass -File .\build-stage24-live-surface-touch-arm64.ps1 -DisplayMode native
```

Default WVGA test mode:
```powershell
powershell -ExecutionPolicy Bypass -File .\build-stage24-live-surface-touch-arm64.ps1
```

The exact recovered native presentation contract from Stage 24.17.0 remains available unchanged through `-DisplayMode native`.
