# v0.26.71a — Stage 24.25.1a Audio asset-discovery hotfix

The Stage 24.25.1 WAV inventory accidentally made `assets/data/sfx` a fatal preflight prerequisite. The project's existing `angry-re` extraction does not necessarily expose a literal `assets/data/sfx` directory, so the build could abort before the native audio audit ran.

This hotfix changes only diagnostic asset discovery:

- `assets/data/sfx` is no longer a required build asset.
- If that directory exists, it remains the preferred WAV audit root.
- If it does not exist, the audit recursively scans the already-proven `assets/data` root.
- If no WAV files exist anywhere in that tree, the WAV inventory reports `wavPayloadAvailable=no` and continues nonfatally.
- ARMv7 AudioMixer/AudioOutput disassembly and runtime audio probes remain enabled.
- No gameplay, rendering, physics, Lua ownership, or audio playback behavior is changed.
