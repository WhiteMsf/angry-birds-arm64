# v0.26.75 — Stage 24.25.5 Audio Ramp Owner + MP3 Decode/Loop Audit

## Evidence entering this stage

Stage24.25.4 separated two behaviors that had previously been conflated:

- untouched Lua really can request track-volume values above `1.0`;
- untouched ARMv7 `audio::AudioMixer::setTrackVolume(float,int)` clamps the
  stored value to `[0,1]`, so vanilla observable mixer state cannot exceed 1.

The runtime also showed the pause SFX toggle itself behaving sanely: one click
sets `settings.audioEnabled=false` and smoothly reduces tracks 7 and 0–4;
the second sets it true and smoothly raises them. The large raw-volume values
appeared later on `levelComplete`, through `setMusicVolume` / `setEffectsVolume`,
not as repeated SFX-button input.

## Runtime audit

No audio behavior is changed beyond the already-proven ARMv7 `[0,1]` track
clamp introduced in Stage24.25.4.

- Traces the original top-level script chunks during bootstrap too, so a top-level `SETGLOBAL` initializer cannot disappear before the post-execution audit.
- Recursively scans every global Lua Proto for `SETGLOBAL` writers of
  `audioRampVolume` and `audioRampLength` and dumps instruction windows.
- While original `updateMenu` owns execution, the existing exact Lua VM hook
  observes those two `SETGLOBAL` instructions read-only and records the exact
  Proto/PC and value about to be written.
- Logs the initial type/value of both globals before native bindings.

Primary runtime report:

- `stage24.25.5-audio-ramp-owner.txt`

## Native MP3 audit

`tools/stage24255_mp3_decode_loop_contract.py` inventories and disassembles the
untouched ARMv7 path around:

- `AudioReader::reset`
- `AudioReader::readData`
- `AudioReader::init_mp3`
- `AudioReader::readHeader_mp3`
- `AudioReader::readData_mp3`
- `AudioReader::deinit_mp3`
- `AudioClip` constructors/lifecycle
- `AudioMixer::playClip`
- `AudioMixer::mixUnlimited8/16/8to16`

It also emits call-graph and conservative machine-readable markers for the
read/reset/decode relationship. It does **not** choose a replacement decoder.

Primary static report:

- `stage24.25.5-mp3-decode-loop-contract.txt`
