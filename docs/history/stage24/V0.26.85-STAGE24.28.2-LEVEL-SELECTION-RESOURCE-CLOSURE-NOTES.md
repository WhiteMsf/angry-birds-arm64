# v0.26.85 — Stage 24.28.2

## Level Selection Resource Closure

Stage 24.28.1 successfully navigated the untouched original Lua state machine
from `levelComplete` into `levelSelectionPagesBasic`. The first real Level
Selection draw then exposed two concrete resource-frontier facts rather than a
menu/state-machine failure.

### 1. Proven bitmap-font transport hole

The runtime had already loaded and parsed the untouched:

- `FONT_LS_SMALL.dat`
- image reference `FONT_LS_SMALL_N900.pvr`
- 13 glyphs
- leading 37
- tracking -1

but Stage24.23.3 only materialized the visible textures for:

- `FONT_BASIC`
- `FONT_BIG_NUMBERS`
- `FONT_SCORE`
- `FONT_MENU`

Therefore `res.drawString()` failed on the first Level Selection text draw even
though the font metadata itself was correct.

Stage 24.28.2 adds `FONT_LS_SMALL.dat` to the same exact local bitmap-font image
transport path. The original PVR remains user-owned and is injected only during
the local build; it is not redistributed in this project ZIP.

### 2. `LS_THEME_1_LEFT` sheet/registry mismatch

The same first frame logged:

`drawSprite("BUTTONS_SHEET_1", "LS_THEME_1_LEFT", ...)`

while the untouched metadata corpus owns both `LS_THEME_1_LEFT` and
`LS_THEME_1_RIGHT` uniquely in `LEVELSELECTION_SHEET_1.dat`.

This revision does **not** assume that a cross-sheet lookup is correct merely
because the desired sprite exists elsewhere. A new build-time ARMv7 audit
recovers the exact native implementation of the two-string overload:

`game::Resources::drawSprite(String const&, String const&, float, float, Anchor)`

and classifies its lookup as one of:

- `GLOBAL_SPRITE_REGISTRY`
- `SHEET_SCOPED`
- `HYBRID_OR_FALLBACK`
- `UNRESOLVED`

Only when untouched ARMv7 proves `GLOBAL_SPRITE_REGISTRY` does CMake compile in
the ARM64 unique-owner cross-sheet resolution. Even then, a name with multiple
retained owners is deliberately left unresolved rather than inventing registry
collision order.

If ARMv7 proves sheet-scoped lookup, the original miss remains a no-op as in the
already recovered missing-sprite semantics.
