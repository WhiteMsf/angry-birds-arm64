# v0.26.86 — Stage 24.28.3

## Menu Render Ownership + Remaining Resource Closure

This revision closes the concrete renderer-ownership bug exposed by the first fully visible
Main/Episode/Level menu traversal in v0.26.85.

### Proven bug

`currentGameMode=updateMenu` was still rendered by the Stage23/24 reconstructed gameplay
surface before the manually-invoked untouched `drawMenu()` closure.  Therefore the final
Level1 world, fixed score/high-score HUD and gameplay pause button remained visible beneath
otherwise-correct original menus.

At the same time untouched `drawMenu()` already contained the original ownership chain:

```
setTheme(currentMainMenuTheme)
drawBackgroundNative()
... birdAnimations ...
drawForegroundNative()
drawMenuPage(...)
```

but Stage24 still registered `drawBackgroundNative` and `drawForegroundNative` as blanket
stubs.

### Change under test

* `updateMenu + currentMenuPage` now owns the complete frame and returns before the gameplay
  world/HUD renderer is entered.
* `drawBackgroundNative` is restored at the exact call site used by untouched `drawMenu()`.
  It reuses the already-recovered ARMv7 `GameLua::drawBackground()` algorithm, including the
  theme RGB background color and repeated/parallax layers.
* `drawForegroundNative` is restored at its untouched call site after menu bird animations and
  before `drawMenuPage()`, reusing the recovered 1.5 foreground scale/ground-color contract.
* Theme sprite resolution can consume either the existing exact scene atlases or exact menu
  atlases. No screenshot fitting or synthetic menu background is introduced.
* Gameplay rendering is unchanged while `currentGameMode` is not `updateMenu`.

### Remaining resource audit

`tools/stage24283_menu_render_ownership_contract.py` inventories the remaining runtime miss
families (`NEW_HIGHSCORE_PT`, `SCORE_PT`, `GOLDEN_EGG_STAR_EFFECT`, `SETTINGS_BG`, the three
`MENU_SLIDER_BG_BOTTOM_*`, and the already-known `LS_THEME_1_*` mismatch) across the untouched
image/script corpus. Missing names are classified only; this revision does not hand-map them.

### Still deliberately out of scope

* startup Clickgamer/Rovio/Angry Birds splash playback;
* first-entry 1-1 story/cutscene;
* persistence/save implementation;
* external Crystal/Ovi/ads/analytics service replacement.

### Test

Finish 1-1, press Menu/Home, then traverse Level Selection -> Episode Selection -> Main Menu
and About/side panels. The old gameplay score/high-score, pause button, slingshot/birds/world
must not remain under the menus. The menu background/foreground must be produced by untouched
`drawMenu()` via the recovered native theme calls.
