# v0.26.89 — Stage 24.29.0: Vanilla Startup / Splash Boot Restoration

## Goal

Restore the user-visible startup path before the already-restored menu tree without inventing branding or refactoring the stable Stage24 gameplay scaffold in the same change.

## Proven original contract

Untouched `updateSplashes()` builds this sequence:

1. `SPLASH_CLICKGAMER` — 2 s — white background
2. `SPLASH_ROVIO` — 2 s — white background
3. `SPLASH_ANGRY_BIRDS` — 1 s — black background

The original iPhone/iPad/iPhone4 branch starts at entry 2. The Android branch does not take that skip in Lua.

The selected Android 864x480 asset corpus, however, retains concrete owners for:

- `SPLASH_ROVIO` -> `SPLASHES_SHEET_2.dat`
- `SPLASH_ANGRY_BIRDS` -> `SPLASHES_SHEET_1.dat`

and no retained owner for `SPLASH_CLICKGAMER` in the currently audited corpus. Stage24.29.0 therefore does **not** fabricate or substitute Clickgamer art: it displays that first entry only if the runtime SpriteDB proves a concrete retained owner. Otherwise it emits an explicit edition-skip audit record and starts at Rovio.

`SPLASH_LOADING` is not a timed entry of the three-element splash table, but the untouched Android branch attempts to draw it as an overlay during `SPLASH_ANGRY_BIRDS`. Its concrete sprite owner is unresolved in the retained 864x480 corpus, so Stage24.29.0 logs that fidelity gap and does not invent/substitute art. This remains a boot-overlay closure item for the next pass if reproduced.

## Runtime architecture

The stable Stage24 bootstrap still materializes Level1 internally before the live loop. During startup branding that scaffold is deliberately frozen and hidden:

- physics disabled;
- original Lua `update()` not called;
- gameplay renderer not called;
- menu 854x480 presentation owns the surface;
- touch DOWN skips the current splash using the recovered LBUTTON behavior.

After the final splash, Stage24 hands control back to untouched menu logic with:

- `newMenuPage = mainMenu`;
- `newMenuPageNeedsPrepare = true`;
- `setGameMode(updateMenu)`.

From that point onward, normal menu callbacks own `Jogar -> Episode Selection -> Level Selection -> level load`.
