# v0.26.9 — Stage 24.6 menu metadata + auditor-scope fix

The v0.26.8 black screen was caused by an obsolete Stage23.0 gate: after menu metadata expanded SpriteDB from two sheets to five, the old audit still required the total loaded sheet count to equal two and returned rc=26 before EGL was created.

The same run also advanced original createMenuPages() to PC 2497 and identified SETTINGS_BG as the next missing sprite.

This release scopes the Stage23.0 invariant to the two Level1 object sheets only, stages the original 864x480 MENU/OTHER metadata family, resolves SETTINGS_BG ownership from the user's untouched DAT files at build time, and changes no physics/camera/input behavior.
