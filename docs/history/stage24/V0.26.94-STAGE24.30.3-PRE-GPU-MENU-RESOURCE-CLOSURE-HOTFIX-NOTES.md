# v0.26.94 — Stage 24.30.3 Pre-GPU Menu Resource Closure Hotfix

## Why this exists

v0.26.93 correctly moved the GLES availability gate after the force=false reuse check, but the next real boot proved the old bootstrap SpriteDB itself was incomplete. Untouched `releaseCutScenes() -> loadImages(OTHER/MENU)` runs before the Stage24 GLES renderer exists and requested `GOLDEN_EGGS_SHEET_2.dat` after successfully reusing six resident sheets. Because that concrete original sheet was not part of the older minimal bootstrap set, the bridge classified it as genuinely dynamic and failed closed with `dynamic GPU bridge unavailable`, producing another all-black startup.

## Contract correction

Stage24.30.3 does **not** defer GPU upload, fake success, or load CUTSCENES early. Instead it restores the prerequisite implied by the original force=false contract: concrete MENU/OTHER sheets that exist in this edition and can be requested by the pre-loader are resident in the bootstrap SpriteDB before the replay begins.

The local build now conditionally adds the concrete edition-local supplemental loadlist sheets when they exist:

- `ACHIEVEMENTS_SHEET_1.dat`
- `GOLDEN_EGGS_SHEET_2.dat`
- `GOLDEN_EGGS_SHEET_4.dat`
- `LEVELSELECTION_SHEET_2.dat`
- `MENU_ELEMENTS_2.dat`
- `MENU_ELEMENTS_3.dat`
- `SPLASHES_SHEET_3.dat`

Missing edition-specific candidates are skipped rather than invented. `GOLDEN_EGGS_SHEET_2.dat` is fail-closed because the v0.26.93 runtime proved this exact corpus requests it.

The six `CUTSCENES_*` sheets remain outside the bootstrap registry and retain Stage24.30.1 dynamic ownership. They should only load after the real 1-1 story path reaches `loadCutScenes()` with GLES available.

## Expected runtime evidence

Before splashes, the old sequence should continue beyond call 6 and include:

`[stage24.30.2-pre-gpu-reuse] ... key='GOLDEN_EGGS_SHEET_2' ... action=REUSE_PRELOADED gpuReady=no`

No `dynamic GPU bridge unavailable` error is expected during the pre-loader. The next genuinely dynamic `CUTSCENES_*` request should occur only after the user enters 1-1 through the vanilla menu path.
