# v0.26.96a — Stage 24.31.0 build hotfix

This hotfix changes **no persistence behavior**.

The v0.26.96 source accidentally made the pre-existing Stage 24.30.0 cutscene Lua bytecode dumper call the newly added `stage24310PrintInstruction()` helper before that helper was declared. Clang therefore failed while compiling `stage24_live_surface.cpp`.

The hotfix restores the original Stage 24.30.0 call:

```cpp
stage24300_print_instruction(p, pc, root);
```

The Stage 24.31.0 persistence dumper continues to use `stage24310PrintInstruction()` in its own later-defined code. No runtime contracts, return values, save semantics, resource behavior, or asset lists were changed.
