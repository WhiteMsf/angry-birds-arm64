# v0.26.97 — Stage 24.31.1: Original Real Save / Restart Persistence

## Scope

Stage 24.31.0 proved the live profile calls and ARMv7 ownership:

- `saveLuaFile("settings.lua", "settings", true)`
- `saveLuaFile("highscores.lua", "highscores", true)`
- `true` selects AppData storage.
- the native binding returns no Lua values.
- `loadLuaFile(path, tableName)` executes the saved Lua table data into a fresh table environment and installs it under `tableName`.

This stage turns only that proven profile path into real app-private persistence. Tutorial first-run behavior and menu micro-fidelity remain deferred to 24.31.2 and 24.31.3.

## Implementation

Profile files live below the app-private Stage24 root:

- `files/stage24/appdata/settings.lua`
- `files/stage24/appdata/highscores.lua`

`saveLuaFile(..., true)` serializes the named Lua table as a textual Lua environment chunk, flushes + `fsync`s a temporary file, then atomically renames it over the profile file. The binding still returns zero Lua values.

At process bootstrap the two files are loaded after the clean default bootstrap exists but before menu/audio initialization consumes `settings` and `highscores`. A successful restart load is logged as `action=PASS_FROM_DISK`.

The textual representation is behaviorally compatible with the recovered `LuaTable::write/read` contract. This stage does **not** claim byte-for-byte identity with KA3D's original writer; exact on-disk formatting is not needed for the restart-behavior gate and can be audited separately if required.

Non-AppData (`appData=false`) save calls were not observed as profile writes in 24.31.0 and remain deliberately unredirected.

## Required two-process test

### RUN A

1. Build/install normally.
2. Boot through Rovio → Angry Birds → Main Menu.
3. Enter Poached Eggs 1-1 through the original story and complete it.
4. Return to menus and toggle audio once.
5. Optionally run `pull-stage24-live-log.ps1` to capture the write-side evidence.

Expected: `WRITE ... settings.lua ... action=PASS` and `WRITE ... highscores.lua ... action=PASS`.

### Restart

Run:

```powershell
powershell -ExecutionPolicy Bypass -File .\restart-stage24-live.ps1
```

This only force-stops and starts the activity. It does **not** reinstall the APK or clear app data.

### RUN B

Verify before changing anything:

- audio state survived;
- 1-1 completion/star/highscore survived;
- 1-2 remains unlocked.

Then run `pull-stage24-live-log.ps1`.

Required log evidence:

- `LOAD file='settings.lua' ... action=PASS_FROM_DISK`
- `LOAD file='highscores.lua' ... action=PASS_FROM_DISK`

The diagnostic ZIP also includes profile file size/SHA evidence and copies of the two textual profile files when present.
