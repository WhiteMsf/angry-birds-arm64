# v0.26.97a — Stage 24.31.1: Automated Persistence Test Driver

This hotfix does not change game/runtime persistence behavior from v0.26.97.
It adds `test-stage24-persistence-auto.ps1` to automate the required two-process
restart proof.

## One-command test

Run:

```powershell
powershell -ExecutionPolicy Bypass -File .\test-stage24-persistence-auto.ps1
```

The script builds/installs/starts the app, then waits while the user completes
Poached Eggs 1-1. It detects successful `settings.lua` and `highscores.lua`
writes automatically, captures RUN A, force-stops/restarts the same installed
app without clearing data, waits for both `PASS_FROM_DISK` markers, captures
RUN B, and emits a final PASS/FAIL bundle.

The user does not need to toggle audio, manually pull logs, press Enter between
runs, or invoke the restart helper. Completing 1-1 is enough to exercise both
profile roots in the observed 1.4.2 Lua flow.

Final evidence bundle:

`stage24-output/stage24.31.1-automated-persistence-test.zip`

Use `-SkipBuild` only when the correct v0.26.97 runtime is already installed.
