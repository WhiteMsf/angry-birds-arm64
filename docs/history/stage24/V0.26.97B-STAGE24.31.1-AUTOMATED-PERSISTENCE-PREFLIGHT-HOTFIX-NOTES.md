# v0.26.97b — Stage 24.31.1 automated persistence preflight hotfix

This is a build/test-helper hotfix over v0.26.97a. Runtime persistence behavior is unchanged.

## Cause

The Stage 24.31.0 static contract auditor was written while persistence was intentionally read-only. It still required the live binding to be `l_stage24310_saveLuaFile` plus the `AUDIT_NO_WRITE` marker. Stage 24.31.1 correctly advances the live binding to `l_stage24311_saveLuaFile`, so the old auditor rejected the intended implementation before compilation.

## Fix

`tools/stage24310_persistence_contract.py` now accepts two explicit ARM64 modes while preserving all ARMv7/script provenance checks:

- `AUDIT_NO_WRITE`: Stage 24.31.0 probe binding and marker.
- `REAL_PERSISTENCE`: Stage 24.31.1 real binding plus `PASS_FROM_DISK` / `PASS_FRESH_ENV` markers.

The dedicated Stage 24.31.1 auditor still independently requires the real binding, app-private storage, atomic `.tmp` write, `fsync`, fresh-environment validation, and profile load before menu/audio initialization.

No gameplay, save format, serializer, loader, menu, tutorial, audio, or physics behavior changed in this hotfix.
