# v0.26.99 — Stage 24.31.3 — UI Micro-Fidelity Contract Audit

Audit-first revision for three user-confirmed visual defects that remain after
first-run tutorial restoration:

- Main Menu settings gear disappears after the first click and returns oddly on
  the next click; stock 1.4.2 keeps it visible and rotates it.
- About/Credits hidden Golden Egg popup draws the egg correctly, but
  `GOLDEN_EGG_STAR_EFFECT` appears detached and moves offscreen in under a
  second instead of rotating around the egg.
- Straight horizontal/vertical seam lines are visible through UI panels,
  including the restored `TUTORIAL_RED` composite.

This revision deliberately does **not** change filtering, UV bounds, pivots,
visibility, or Lua animation state. It adds:

1. ARMv7 static audit of `SpriteSheet::drawSprite`, `Resources::drawCompoSprite`,
   Lua resource draw wrappers, and `GameLua::setRenderState`.
2. Original-script literal provenance for `MAIN_SETTINGS_*`, Golden Egg effect,
   visibility/rotation and composite drawing.
3. Live target telemetry with raw sprite rect, pivot, atlas size, submitted quad,
   current edge UVs, hypothetical half-texel UVs, and current render state.
4. Per-part `drawCompoSprite` geometry for diagnosing the UI seam family.

The next revision may implement fixes only after runtime reproduction identifies
whether each defect is caused by Lua visibility/animation state, transform/pivot
semantics, or sprite-sampling geometry.
