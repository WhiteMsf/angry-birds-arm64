# v0.6.1 — Stage 5 probe correction

The v0.6 runtime itself worked. The semantic test failed because the two probe
bodies were intentionally moving toward each other:

- box: center x=0, width=2, vx=+1.5
- circle: center x=3, radius=0.5, vx=-0.5

During the one-second simulation they collided. Box2D correctly changed their
horizontal motion, so the old assertion `circle.x < 3` was invalid. The observed
circle position `x=3.180577` is consistent with real collision response, not a
bridge failure.

v0.6.1 moves the circle to x=10 so the Stage 5 test measures basic integration
without body-body collision. It now checks approximately:

- box x ~= 1.5 after 1 second
- circle x ~= 9.5 after 1 second
- both bodies fall under gravity
- the recovered mass, impulse, angle normalization, initialize() scale and
  physics state checks remain unchanged

Collision response gets its own later test rather than contaminating the basic
GameLua/Box2D bridge probe.
