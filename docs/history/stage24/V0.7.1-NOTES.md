v0.7 successfully materialized the entire real Level1:

- 21 raw `world` entries
- 20 original non-ground objects created through original `createObject()`

- 17 boxes + 4 circles
- 18 dynamic + 3 static bodies

`RedBird_4` and `SmallPiglette_7`, but the actual Level1 instance names are
`RedBird_1`/`_2`/`_3` and `SmallPiglette_1`.

v0.7.1 changes the sample verification to locate the first body by the
`RedBird_` and `SmallPiglette_` prefixes. The physics/materialization code itself
is unchanged.
