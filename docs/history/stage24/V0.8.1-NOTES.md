# v0.8.1 — Stage 7 post-initialize bootstrap fix

v0.8 reached the original `loadLevelInternal()` but failed before the native
`loadLevel()` call with:

`attempt to index field 'ingamePausePageScroll' (a nil value)`

The headless bootstrap had already created:

`elementAnimations.ingamePausePageScroll = { percentage = 100 }`

but it ran **before** the original `initialize()`. The original initialization
rebuilds several UI/game-state tables, so the seeded field was gone by the time
`loadLevelInternal()` started.

v0.8.1 keeps the original initialize path unchanged and re-applies only the
headless structural bootstrap immediately afterward. It also prints the field
type before and after restoration, so the next run proves whether the diagnosis
is correct.

No physics, Level1, Box2D, `loadLevel()`, `filterLoadedLevel()` or
`createObject()` behavior was changed.
