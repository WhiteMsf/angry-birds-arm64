# v0.9.1 — restore full Stage 7 loader scaffold

v0.9 failed inside the original `loadLevelInternal()` before the frame loop:

`attempt to perform arithmetic on global 'pauseBGw' (a nil value)`

This was a harness regression, not a new reverse-engineering barrier.

Stage 7's successful headless loader bootstrap had supplied several structural
globals used by `loadLevelInternal()`, including:

- `pauseBGw`
- `screen`
- `levelStartPosition`
- `rubberBandPos`
- `baitSardine`
- score increment globals
- the pause-page shape

When Stage 8 was created, its slimmer startup bootstrap accidentally omitted
those fields. v0.9.1 restores the full proven Stage 7 scaffold, while keeping
the new Stage 8 frame-loop code unchanged.

No Lua game logic, Level1 data, Box2D behavior, native loader semantics, or
physics<->Lua synchronization changed.
