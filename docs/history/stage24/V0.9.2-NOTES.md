# v0.9.2 — headless audioGroups scaffold

v0.9.1 successfully reached the **first call to the original `update()`**:

- the original Level1 loader returned normally;
- 21 bodies were alive;
- the active bird was `RedBird_4`;
- frame 1 advanced `time` to 1/60 and `currentFrame` to 1.

It then failed on:

`attempt to index global 'audioGroups' (a nil value)`

Static bytecode inspection identified the exact helper as original
`getAudioName(name)` (18 instructions). Its behavior is:

1. read `audioGroups[name]`;
2. if that entry is nil, return `name` unchanged;
3. otherwise choose a random element from the group's array.

Therefore an **empty `audioGroups = {}`** is the correct headless resource
boundary: it preserves the original fallback path instead of replacing
`getAudioName()` or inventing audio data.

The actual audio output functions remain no-ops in Stage 8.

No gameplay, physics, loader, Box2D, bird-state, or update logic was changed.
