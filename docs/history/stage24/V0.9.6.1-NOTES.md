# v0.9.6.1 — Lua 5.1 compatibility compile fix

v0.9.6 failed at compile time because the new camera-profile helper used
`lua_absindex()`.

`lua_absindex()` is not part of the Lua 5.1 C API; it was introduced in later
Lua versions. This project intentionally uses patched Lua 5.1.5, so the helper
now performs the equivalent absolute-index normalization manually:

```cpp
if (envIndex < 0 && envIndex > LUA_REGISTRYINDEX)
    envIndex = lua_gettop(L) + envIndex + 1;
```

Pseudo-indices such as `LUA_REGISTRYINDEX` are preserved unchanged.

No runtime logic, camera-profile mapping, Box2D behavior, Lua gameplay code, or
Stage 8 frame-loop behavior changed. This patch only fixes the compile barrier.
